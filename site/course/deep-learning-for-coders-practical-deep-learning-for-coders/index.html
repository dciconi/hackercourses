Deep Learning for Coders (Practical Deep Learning for Coders)

fast.ai

2 recommenders · 2 threads · recommended in 2 years, 2019–2022 · score 1.7

Search for it ↗

A practical, top-down introduction to deep learning taught by fast.ai, built around writing code and training models early before the underlying theory. It covers applications such as computer vision, NLP, and tabular data using a high-level library.

Commenters recommend it as the place to start, call it beginner-friendly and almost paint-by-numbers, and suggest doing projects from it before going back to the math.
