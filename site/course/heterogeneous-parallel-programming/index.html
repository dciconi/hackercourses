Heterogeneous Parallel Programming

Coursera

2 recommenders · 2 threads · recommended in 2 years, 2014–2016 · score 1.8

A Coursera course from the University of Illinois on parallel programming across heterogeneous hardware such as GPUs, taught mainly with CUDA and also covering OpenCL. It is aimed at learning GPU programming.

Commenters point to it as a strong option for learning GPU programming, with one calling it an excellent class taught by Wen Mei Hwu.
