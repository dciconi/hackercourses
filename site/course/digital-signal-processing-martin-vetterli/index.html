Digital Signal Processing (Martin Vetterli)

Coursera

2 recommenders · 2 threads · recommended in 2 years, 2017–2019 · score 1.8

Go to course ↗

An introductory digital signal processing course by Martin Vetterli covering sampling, the DFT, and filtering, with Python notebooks and quizzes. It builds up to how any finite signal can be written as a combination of complex exponentials.

Commenters call it a highly recommended DSP course that explains the math behind the DFT clearly, with useful Python notebooks.
