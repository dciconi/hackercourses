EE263 Introduction to Linear Dynamical Systems

Stanford University

4 recommenders · 4 threads · recommended in 3 years, 2011–2020 · score 3.7

Go to course ↗

Stanford graduate course on linear dynamical systems taught by Stephen Boyd, covering how real problems are formulated so computers can solve them, with topics like matrix rank, norms, and singular values applied to system stability and robustness.

Commenters call it really good and praise Boyd as a very entertaining, clear lecturer who shows how to turn real problems into computable form.

  4. Recommendsdvse2011in “Ask HN: How do I start with Machine Learning?”

    Start with the MIT linear algebra course (18.06) by Gilbert Strang and Stanford course on linear dynamical systems (EE263) by Stephen Boyd. Then move on to Boyd's course on convex optimization (EE364). Lectures for all of these are on youtube.

    Do not try to read any books on "machine learning" (most of which are a total mess) before you have this background or you will just end up hopelessly confused.
