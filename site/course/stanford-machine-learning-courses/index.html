Stanford Machine Learning courses

Stanford University

2 recommenders · 2 threads · recommended in 2 years, 2022–2023 · score 1.6

Stanford University's machine learning courses, most notably Andrew Ng's Machine Learning course, which covers supervised and unsupervised learning, model evaluation and the underlying theory and practice. It is offered as a set of lecture-based course material.

Commenters point to it as a solid starting point for learning machine learning, with one suggesting people work through its syllabus lesson by lesson and another recommending it after building up linear algebra, probability and statistics.
