CS165 Data Systems

Harvard University

1 recommender · 2 threads · recommended in 2 years, 2020–2023 · score 1.1

Go to course ↗

CS165 Data Systems is a Harvard graduate-level course on building storage engines for relational databases, covering memory hierarchy, buffer pools, B-Tree indexes, and query optimization. A recurring project has students build a columnar relational datastore in C.

Commenters call it a great course for learning how database storage engines are built, and point to its project-based approach and readily available slides and readings.

  2. Recommendsboberoni2020in “If All You Have Is a Database, Everything Looks Like a Nail”

    For people who are interested, Harvard's CS165[1] is a great course about how to build storage engines for relational databases.

    Topics include memory vs disk I/O, the memory hierarchy, buffer pools, B-Tree indexes, query optimization, and more. Throughout the course, you have a project to build a columnar relational datastore with C.

    I don't think the lecture videos are all publicly available, but you can learn a lot from the slides and readings.

    [1]: http://daslab.seas.harvard.edu/classes/cs165/
