6.0001 Introduction to Computer Science and Programming in Python

MIT OCW

2 recommenders · 2 threads · recommended in 2 years, 2015–2022 · score 1.5

An MIT introductory course teaching computer science and programming in Python, covering core programming concepts, sorting algorithms, and dynamic programming. The OCW version is the one linked in the comments.

Commenters recommend it as a solid Python-based introduction to programming and algorithms, though one commenter prefers Harvard's CS50 as a starting point.
