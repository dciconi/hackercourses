CS184 Foundations of Computer Graphics is a UC Berkeley course offered on edX covering the fundamentals of computer graphics, including rendering and the matrix transforms used in OpenGL-style pipelines.

One commenter recommends it for anyone interested in learning more about computer graphics, while noting it uses some deprecated OpenGL but is still quite worthwhile.
