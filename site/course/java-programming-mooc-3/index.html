Java Programming MOOC

University of Helsinki

2 recommenders · 2 threads · recommended in 2 years, 2016–2020 · score 2.3

Search for it ↗

A free, self-paced introductory programming course from the University of Helsinki that teaches programming basics through Java. It combines written lessons with many practice exercises completed in an IDE with automated tests, and covers how things are done in professional settings.

Commenters call it a great free introduction to programming with a good first look at Java, and one says they know of no better free option for learning a programming language.
