Relational Algebra

Stanford Lagunita

2 recommenders · 2 threads · recommended in 2 years, 2015–2017 · score 1.5

Go to course ↗

A Stanford Lagunita self-paced mini-course on relational algebra, the formal foundation underlying SQL and relational databases. It is part of Jennifer Widom's database series that was split into smaller courses.

Commenters recommend taking it before the SQL course because it gives insight into how SQL works, since SQL derivatives are based on relational algebra.
