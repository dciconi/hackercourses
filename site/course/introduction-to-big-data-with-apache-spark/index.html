Introduction to Big Data with Apache Spark

edX

2 recommenders · 2 threads · recommended in 1 year, 2015 · score 1.4

Go to course ↗

An introductory edX MOOC from UC Berkeley (CS100.1x) on big data processing with Apache Spark. It covers distributed data analysis with Spark, including assignments that build a recommender on the MovieLens dataset.

Commenters recommend it as a way to get started with Spark and big data, and one points to its MovieLens recommender assignment.
