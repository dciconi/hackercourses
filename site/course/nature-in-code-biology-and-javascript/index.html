Nature in Code: Biology and Javascript

edX

1 recommender · 1 thread · recommended in 1 year, 2017 · score 0.7

A free edX course from EPFL that uses JavaScript to build simulations of biological systems and natural processes, such as evolutionary dynamics. It is the MOOC companion to the Nature of Code style of programming-for-simulation material.

One commenter recommends the MOOC and its book together for learning evolutionary dynamics through JavaScript simulations.
