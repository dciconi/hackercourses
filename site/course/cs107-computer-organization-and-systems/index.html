CS107 Computer Organization & Systems

Stanford University

2 recommenders · 2 threads · recommended in 2 years, 2010–2012 · score 1.9

Go to course ↗

CS107 is Stanford's second-level programming course on how computers run programs, covering C, memory management, pointers, and the layers between code and hardware. It is offered through Stanford's free Stanford Engineering Everywhere video lectures.

Commenters point to it as a solid way to learn C and the memory-level details that higher-level languages hide, with one saying it is a good alternative to skipping C in a CS degree.
