Cryptopals Crypto Challenges

cryptopals.com

Cryptopals is a set of hands-on cryptography challenges that walk through attacking real-world crypto schemes and weak implementations, so learners build an intuitive sense of how attacks work and how severe they are.

Commenters suggest it as a practical way to build a gut-level understanding of the severity of various cryptographic attacks, alongside more basic courses.
