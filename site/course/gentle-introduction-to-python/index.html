Gentle Introduction to Python

MIT OpenCourseWare

2 recommenders · 2 threads · recommended in 2 years, 2010–2015 · score 1.7

An MIT OpenCourseWare introductory programming course (6.189, IAP 2010) taught in Python, covering the basics of programming and building small projects such as a Tetris game.

Commenters point to it as a good starting point for absolute beginners, and one says it works well alongside Udacity's Intro to Programming because it covers classes, which Udacity skips.
