CPSC 110 Computation and Programming

University of British Columbia

1 recommender · 1 thread · recommended in 1 year, 2022 · score 1.0

Go to course ↗

CPSC 110 Computation and Programming is an introductory University of British Columbia course teaching programming from first principles, using the How to Design Programs (HtDP) curriculum and a Scheme-based language, covering simple and complex data. It requires no prior background.

Commenters call it the best course they've taken and note it can be completed for free, with no background requirements.

  1. Strongly recommendsTheGrkIntrprtr2022in “Ask HN: It's 2022. Where should I direct the youths to learn about programming?”

    I took CPSC 110 at UBC with Gregor Kiczales (who worked at Xerox PARC). It was the best course I’ve ever taken.

    The course can also be completed for free: https://www.edx.org/bio/gregor-kiczales

    How to code - simple data, and how to code - complex data together make up the material in CPSC 110 (though there are probably some differences). They’re completely accessible with no background requirements.

    The courses are based on this curriculum, which uses HTDP: https://programbydesign.org/

    The programming language used is based on scheme.
