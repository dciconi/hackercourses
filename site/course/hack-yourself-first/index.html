Pluralsight

A Pluralsight course by Troy Hunt that teaches web application security by showing common attacks first, so developers learn the basics from the attacker's side. It is aimed at web developers who want a hands-on introduction to security.

Commenters recommend it as a hands-on introduction to web security that covers the basics from the attack angle first.
