CS229A Applications of Machine Learning

Stanford University

1 recommender · 1 thread · recommended in 1 year, 2017 · score 0.7

Search for it ↗

CS229A is Stanford's applied machine learning course taught by Andrew Ng, focusing on practical ML methods and how to apply them to real problems rather than on the deeper theory covered in CS229.

Commenters praise Andrew Ng's teaching as making machine learning engaging and practical, and one contrasts it favorably with Geoffrey Hinton's neural network course.
