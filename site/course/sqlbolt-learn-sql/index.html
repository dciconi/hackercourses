SQLBolt is a free, interactive browser-based tutorial that teaches SQL through short lessons and exercises with immediate feedback. It covers basic queries through joins and aggregate functions.

One commenter says they really enjoyed it and recommends checking it out alongside Khan Academy's SQL course.
