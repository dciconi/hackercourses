CS50's Web Programming with Python and JavaScript

edX

2 recommenders · 2 threads · recommended in 2 years, 2022–2024 · score 1.5

A Harvard-taught edX course that follows CS50's Introduction to Computer Science and covers building web applications with Python and JavaScript, including server-side and client-side pieces and how they fit together.

Commenters recommend it as the follow-up to CS50 for learning full-stack web development through assignments and projects, and one calls it a way to see how the components fit together.
