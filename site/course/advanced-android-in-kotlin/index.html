Advanced Android in Kotlin

Google Developers

A Google Developers codelab-based course that builds on basic Kotlin and Android knowledge to teach more advanced Android app development in Kotlin. It is delivered as online codelabs.

Commenters point to it as a way for a Java developer to get into Kotlin and Android after the Kotlin bootcamp, with the codelabs linked as a next step.
