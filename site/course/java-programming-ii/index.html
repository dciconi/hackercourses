Java Programming II

University of Helsinki

2 recommenders · 2 threads · recommended in 2 years, 2018–2021 · score 2.4

A University of Helsinki MOOC (hosted at mooc.fi) that continues from the first Java course, covering further core Java programming for learners who already know the basics.

Commenters describe mooc.fi's Java courses as really great for learning Java from scratch, and one says Java I and II together would make a person a better programmer than many front-end certificate completers.
