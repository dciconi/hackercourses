CS 106L Standard C++ Programming

Stanford University

1 recommender · 1 thread · recommended in 1 year, 2013 · score 0.7

Search for it ↗

CS 106L is Stanford's course on Standard C++, covering modern language features and the standard library, including the STL, the C++ object model, operator overloading, and functors. Its course reader, written by Keith Schwarz, is the material commenters point to.

Commenters recommend the course reader as a fast way to get up to speed on major parts of STL and the C++ object model, assuming a prior programming background.
