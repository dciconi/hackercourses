Machine Learning (Yaser Abu-Mostafa, Learning From Data)

Caltech

2 recommenders · 2 threads · recommended in 2 years, 2013–2019 · score 1.7

Search for it ↗

An introductory machine learning course by Caltech professor Yaser Abu-Mostafa, covering the theory and fundamentals of learning from data. It is delivered as video lectures and is more mathematically oriented than many introductions.

Commenters point to it as a math-oriented introduction to ML that focuses on fundamentals, and one suggests it as a good complement to self-study alongside other material.
