Cryptography and Data Security

Worcester Polytechnic Institute

A graduate-level course in cryptography and data security taught at Worcester Polytechnic Institute, covering encryption and security fundamentals. One commenter's end-of-course project was a full C implementation of the Rijndael cipher, the basis of AES.

One commenter, a former student, calls it one of their favorite grad classes and recalls building a complete Rijndael implementation as the final project.
