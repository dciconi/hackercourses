6.170 Software Studio

MIT OpenCourseWare

2 recommenders · 2 threads · recommended in 2 years, 2020–2023 · score 1.8

Go to course ↗

MIT's Software Studio course (6.170), taught by Professor Daniel Jackson, covers designing and building software systems, with emphasis on user interface design heuristics and software abstractions. The 2018 materials include video lectures.

Commenters point to its video lectures as a strong primer on UI/UX heuristics and as a source on software abstractions from Professor Jackson.
