Performance Aware Programming

computerenhance.com

3 recommenders · 4 threads · recommended in 2 years, 2023–2025 · score 2.9

Search for it ↗

A course by Casey Muratori on writing performance-aware software, working from x86-64 assembly and machine code up to measuring and optimizing real programs. The first part has students build a simulator for the Intel 8086 instruction set.

Commenters call it a great course for experienced programmers who want to understand how to measure and write high-performance code, and praise its hands-on look at how instructions are encoded.
