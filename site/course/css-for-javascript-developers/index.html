CSS for JavaScript Developers

Josh Comeau

6 recommenders · 7 threads · recommended in 5 years, 2022–2026 · score 7.5

Search for it ↗

A paid, self-paced web course by Josh Comeau that teaches CSS by building a mental model of how it works for developers who already know JavaScript. It focuses on patterns, gotchas, and layout and styling techniques rather than listing property definitions.

Commenters say it goes beyond property reference to show real usage patterns and common pitfalls, and that it is fun and builds real confidence in CSS.
