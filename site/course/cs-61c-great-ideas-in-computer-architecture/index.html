CS 61C Great Ideas in Computer Architecture

UC Berkeley

5 recommenders · 6 threads · recommended in 6 years, 2007–2023 · score 5.7

Go to course ↗

CS 61C, UC Berkeley's introductory computer architecture course, covers how machines work from C and assembly through CPU design, including number representation such as floating point. Its lectures are available free as video recordings, with some lectures varying between years.

Commenters call it a transformative foundation for understanding how computers actually work, and recommend it especially for learning C and C++ and machine-level behavior.

    (As you know) most of the lower div EECS courses inherit slide decks and the coverage is set by the department. CS70 has a wonderful set of notes which should be a book.
