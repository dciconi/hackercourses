Machine Learning Specialization (University of Washington, Carlos Guestrin and Emily Fox)

Coursera

3 recommenders · 3 threads · recommended in 1 year, 2016 · score 4.8

Go to course ↗

A three-course Coursera specialization from the University of Washington, taught by Carlos Guestrin and Emily Fox, covering core machine learning methods such as regression, classification, and neural networks, with Python-based assignments. It explains the underlying math without going deep into theory.

Commenters call it well organized with good lectures, and say it explains the math behind the algorithms in a rigorous but approachable way.

  1. Strongly recommendstgokh2016in “Ask HN: What is your goto resource for learning about big data, ML, AI etc?”

    I'm a huge fan of the rest of this Coursera specialization (or was, until they started charging to submit assignments for it mid-specialization, but I digress...)

    Carlos and Emily do a great job diving deeper than most other online courses into the math behind different algorithms without making the math too theoretical. I'm a grad student in engineering, so I wanted to understand not only how to run these algorithms but also how they work and these courses were great for learning in a mathematically rigorous but still approachable sort of way.

    The only criticism I've heard of this series is that it uses Turi/Dato/Graphlab instead of SciKit-Learn. I did the courses that exist so far using GraphLab, but I'm starting to redo the assignments using SciKit now so that I learn that toolkit as well.

    It's also salient to know that, over the next decade, while tech salaries will likely trend down (esp. as CoPilot, nocode/lowcode, etc continue to make our lives easier and hence less lucrative ;D) the *amount of addressable work* in ML specifically will almost certainly offset this change.
