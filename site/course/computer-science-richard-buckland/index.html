Computer Science (Richard Buckland)

YouTube

1 recommender · 1 thread · recommended in 1 year, 2012 · score 1.0

A university-level introductory computer science lecture series by Richard Buckland, recorded at UNSW, running about 50 lectures from machine code up through software engineering. It is distributed free on YouTube.

Commenters call it a compelling starting point that covers the fundamentals in a way they say usually only a classroom provides.
